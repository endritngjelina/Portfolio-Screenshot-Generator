# Portfolio Screenshot Generator

A web-based tool for generating clean, professional screenshots of web projects for portfolios, documentation, and presentations.

This project streamlines the process of creating consistent preview images for websites and web applications. Throughout development, multiple versions were created to refine the interface, improve automation, and enhance the screenshot generation workflow.

## Features

- 📸 Generate portfolio-ready screenshots
- 🖥️ Browser-friendly interface
- ⚡ Fast screenshot workflow
- 🎨 Consistent image formatting
- 📱 Responsive design
- 🧩 Multiple development iterations
- 💼 Ideal for showcasing web projects

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/endritngjelina/Portfolio-Screenshot-Generator.git
```

### Run locally

Open the latest HTML file directly in your browser, or run the project using a local development server.

Using Python:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```

Alternatively, use the **Live Server** extension in Visual Studio Code.
